Why EVVora

Built around the four things a 245D reviewer checks.

Units

Counted the way DHS bills

Every note is measured in fifteen-minute units against the authorization, so what you bill is what you did.

Codes

From the DHS list, not typed

Service codes and modifiers come from the published list. A note cannot carry a code the state does not know.

Signature

The client co-signs

A signing code at clock-out, rotated weekly, so every note carries the client's own mark beside the caregiver's.

EVV

Checked before billing

Clock-in, clock-out and location are verified on every visit and queued for the state aggregator.

The product

Everything about a person, in one place.

Notes, schedule, outcomes, medication, documents and the personnel file. No second system for the plan or the pills.

Every write is logged

Who changed what, when, and what it said before. Reading a signing code is logged too.
